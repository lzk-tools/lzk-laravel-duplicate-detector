## Production-support blockers

- PostgreSQL and MySQL have no engine-specific integration evidence.
- PHP 8.3 and 8.5 remain experimental until hosted CI succeeds.
- RR-006 remains: unknown configuration keys and exception taxonomy are provisional.
- No production-scale benchmark or operational support policy exists.

## Documented limitations

- Consumers own authorization and tenant correctness of the mandatory scope.
- Blocking and finite candidate limits can omit duplicates.
- Keyset iteration does not provide snapshot consistency under concurrent writes.
- Read-only behavior is verified at package-query level, not enforced as a database permission.
- Results are candidate evidence and classifications, not probabilities, identity decisions, or merge authorization.

## Post-publication improvements

- Add engine-selectable integration tests and isolated PostgreSQL/MySQL CI services.
- Promote successful PHP 8.3/8.5 rows only after evidence exists.
- Stabilize configuration errors and advanced extension APIs before 1.0.
- Add reproducible benchmarks and a documented maintenance window.
