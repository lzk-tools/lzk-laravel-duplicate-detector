# Roadmap: proposed Free / Pro

This is planning, not a licensing commitment, product offer or release schedule.
The package is not commercially ready.

| Phase | Scope | Status |
| --- | --- | --- |
| 1 | Composer foundation, contracts, config and testing | Complete |
| 2A/2A.1 | Exact engine and pagination audit | Complete |
| 2B | Fuzzy similarity, SQL blocking and contradictions | Complete |
| 2C | Deterministic explainable classification | Complete |
| 3A | Declarative model configuration, container manager and scoped public API | Implemented, provisional API |
| Later | Production evaluation, database matrix and benchmarks | Requires approval |
| Release | Legal review, stable API and distribution readiness | Undecided |

Possible Free scope remains basic exact/fuzzy detection, deterministic policies
and the configured read-only API. Possible Pro scope may include additional local
strategies, resumability, performance tooling and supported presets. These are
proposals; no Pro implementation exists.

Release gates include verified security reporting, remaining Pro pricing/terms, stable configuration/API
review, evidence-code lifecycle, wider PHP/database execution, representative
quality evaluation and performance benchmarks.

No machine learning, dashboard, automatic merge or record mutation is planned by
this phase. Work stops after Phase 3A until explicit approval.
